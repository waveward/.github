## Waveward

Open, play, export, recover and downgrade Audacity project files (.aup4 and .aup3) in the browser. The project is parsed on your own device and never uploaded.

- Use it: [aup4.aivismonitor.com](https://aup4.aivismonitor.com/)
- Field notes on the format: [audacity-project-formats](https://waveward.github.io/audacity-project-formats/), checked against the Audacity source
- Built by [Lei Wang](https://github.com/leivorn). Waveward is an independent tool and is not affiliated with Audacity or Muse Group.
